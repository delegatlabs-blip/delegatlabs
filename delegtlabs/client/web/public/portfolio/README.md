# Portfolio Images

This folder contains project images for portfolio items displayed throughout the site.

## Required Images

Place the following images in this folder with these exact names:

- `cranes-24.png` - Cranes 24 project image
- `neostox.png` - Neostox project image
- `om-anmol.png` - Om Anmol project image
- `avis.png` - Avis project image
- `enigma.png` - Enigma project image
- `rekhta.png` - Rekhta project image

## Image Format

- Format: PNG or JPG
- Recommended dimensions: 800x600px (4:3 aspect ratio) or 1200x800px
- File size: Keep under 500KB for optimal performance
- Quality: High quality images that represent your work well

## Usage

These images are referenced in `/data/portfolio.ts` and displayed in:
- Portfolio section on the homepage
- Portfolio listing page
- Individual portfolio project detail pages

## Adding New Projects

When adding new portfolio items, add the corresponding image file here with the same name as the project slug.
