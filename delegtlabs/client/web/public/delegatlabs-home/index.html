Follow-up Agent

From a waiting submission to a follow-up draft.

Input
A recruiter identifies a candidate submission that is still waiting on client feedback.
Agent prepares
A follow-up draft tied to the original submission, ready for a manager to review.
Human decision
The manager checks the wording. The recruiter decides whether and when to send.
See an illustrative example
Sample input
A recruiter submitted two candidate profiles on Monday and has heard nothing by Thursday.
Sample output
“Hi, have you had a chance to review the two profiles we sent on Monday? Let me know if you’d like more information or an interview slot.”
What a person checks
The recruiter checks whether the client already replied in another thread and decides whether to send.

Affidavit drafting

From case facts to a first affidavit draft.

Input
An advocate enters the facts for a name-correction affidavit and selects English or Hindi.
Agent prepares
A structured first draft in the selected language, using the facts supplied by the advocate.
Human decision
The advocate checks names, dates and wording, then revises the draft before use.
See an illustrative example
Sample input
The advocate records two spellings of a fictional client’s name and asks for a first draft in English.
Sample output
“The name appears as [recorded spelling] in [document] and as [correct spelling] in [supporting record].”
What a person checks
The advocate compares both spellings with the source documents and checks the declaration before using it.

Haazir AI

From a client question to a proposed case update.

Input
A client messages the chamber on WhatsApp to ask whether their case has progressed.
Agent would prepare
Haazir would use available case details to suggest a status reply for the chamber.
Human decision
The advocate would check the details and approve the reply before release.
See an illustrative example
Sample input
“Has my next hearing been scheduled?” The chamber’s internal record has no confirmed date.
Sample output
“We’re checking the latest listing. We’ll update you as soon as the next date is confirmed.”
What a person checks
The advocate checks the current listing and decides whether to send the reply or replace it with a confirmed date.

LinkedIn Growth Agent

From research and post ideas to a reviewable draft.

Input
A team defines its audience, topic, and outreach criteria.
Agent prepares
The product organizes potential leads and prepares post or outreach drafts.
Human decision
A person checks relevance and wording, then chooses what to publish or send.
See an illustrative example
Sample input
A hiring consultancy wants a post for HR leads about why candidate submissions stall.
Sample output
“When a submission stalls, agree who owns the next step and when they’ll follow up.” The example review list groups potential leads by role.
What a person checks
The team checks the target roles and wording, then chooses whether to publish the post or reach out separately.
